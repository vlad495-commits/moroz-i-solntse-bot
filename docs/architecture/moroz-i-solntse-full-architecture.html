13 · Privacy, security и 152-ФЗ

До внешней LLM

  • versioned processing consent и отдельная рекламная семантика;
  • privacy gate до долгого хранения и внешнего вызова;
  • typed PII masking и scripts-first guardrails;
  • current-only Security `OK/BLOCK`; double failure — safe alert и local-only fail-open.

Внутри контура

  • секреты только через environment boundary;
  • safe logging без токенов, URL credentials и исходных ПД;
  • RBAC, CSRF, server-side sessions, TOTP-ready и audit;
  • PostgreSQL — источник критичного состояния.

Юридическая граница

Архитектура поддерживает требования 152-ФЗ техническими мерами, но не объявляет окончательное юридическое соответствие. Retention, тексты согласий и правила обработки остаются предметом production acceptance.
