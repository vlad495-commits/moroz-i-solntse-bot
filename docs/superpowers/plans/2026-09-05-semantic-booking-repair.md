# Исправление диалога и Telegram-записи

**Основание:** пользователь утвердил единый LLM-роутинг свободного текста и исправление связанных дефектов 2026-09-05. По просьбе пользователя создана отдельная ветка `codex/semantic-booking-repair` от чистой `codex/bot-logic-fixes`.

**Архитектура:** существующий SecurityPipeline маскирует ПД, проверяет безопасность и получает единственное семантическое решение. После allow передаёт решение обработчику сценария; worker сохраняет ответ и кнопки через существующий outbox. Кнопки и Telegram contact остаются техническими событиями. Внешние mutations выполняются только BookingService после подтверждения.

Референс: Lucky Hair `5398f90`, изученные в диагностике `project/llm/router.py`, `project/llm/worker.py`, `booking_chain.py`. Переносим единое решение и dispatch; сохраняем наш durable inbox/outbox, security, ownership и BookingService.
