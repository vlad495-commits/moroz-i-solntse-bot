# Полноширинные вкладки Evaluations — дизайн

## Цель

Заменить строку обычных подчёркнутых ссылок над заголовком Evaluations на визуально цельную панель вкладок, согласованную с карточками и цветами админки.

## Решение

- Существующие `<nav class="eval-tabs">` и ссылки остаются без изменений: URL, RBAC и семантика навигации уже корректны.
- На desktop `eval-tabs` становится полноширинной сеткой из пяти равных сегментов. Для роли `admin`, которой доступна одна вкладка, единственный сегмент занимает всю ширину.
- Контейнер получает светлый полупрозрачный фон, рамку, скругление и лёгкую тень из существующей дизайн-системы.
- Активный сегмент получает синюю заливку и белый текст; hover и keyboard focus остаются заметными.
- На экранах до 700 px панель переходит в горизонтальную прокрутку с читаемой минимальной шириной вкладок.

## Границы

Меняется только `project/admin/static/styles.css` и CSS-контракт в существующем тесте навигации. JavaScript, новые зависимости, маршруты, шаблон, права доступа и данные не меняются.

## Проверка

Docker-тест сначала должен зафиксировать отсутствие нового layout-контракта, затем пройти после минимальной CSS-правки. После этого выполняются все тесты `test_eval_navigation.py`, Compose config-check и Docker compileall.
