# Панель действий Evaluations — дизайн

## Цель

Привести заголовок и действия набора Evaluations к спокойной симметричной композиции без изменения маршрутов, данных и поведения runner.

## Согласованное решение

- Заголовок набора выводится отдельной строкой.
- Под заголовком располагается полноширинная светлая панель.
- Для основной LLM недоступность режима с валидатором показывается отдельным приглушённым статусом без неактивного checkbox.
- Три действия располагаются в равной трёхколоночной сетке; все кнопки имеют одинаковую ширину и высоту.
- Основное действие остаётся синим, два остальных — вторичными.
- На экране до 700 px действия складываются в один столбец.
- Тексты, POST-маршруты, CSRF, disabled-состояния и RBAC не меняются.
