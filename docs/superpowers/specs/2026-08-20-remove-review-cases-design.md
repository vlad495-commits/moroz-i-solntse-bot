# Удаление «Review кейсов» из админки

> Release-коррекция 2026-08-28: runtime/UI-модуль остаётся полностью удалённым,
> но физическое `eval_case_reviews` storage сохраняется до истечения окна
> image-only rollback предыдущего admin image. Contract-удаление таблицы вынесено
> за текущий release; это supersedes пункты ниже об удалении таблицы сейчас.

## Цель

Полностью удалить из действующего приложения отдельный модуль «Review кейсов», потому что он больше не нужен владельцу.

## Граница изменения

- убрать пункт «Review кейсов» из бокового меню;
- отключить и удалить маршруты `/review/evals` и их обработчики;
- удалить шаблон страницы и отдельный слой доступа к данным review-кейсов;
- удалить CSS, который используется только этой страницей;
- новой Alembic-миграцией удалить таблицу `eval_case_reviews` вместе с данными;
- удалить или скорректировать только тесты и проверки, относящиеся к этому модулю.

Обычные технические Evaluations, страница «Записи», guardrails со значением `review`, другие таблицы, маршруты и функции админки не меняются. Общие CSS-классы сохраняются, если их использует другая страница.

## Ожидаемое поведение

- ссылки «Review кейсов» в меню нет;
- запросы к прежним `/review/...` возвращают `404`;
- таблицы `eval_case_reviews` в актуальной схеме PostgreSQL нет;
- остальные страницы админки и Evaluations продолжают работать как раньше.

## Проверка

Изменение выполняется через RED/GREEN: сначала тест фиксирует отсутствие ссылки, маршрутов и таблицы, затем удаляется минимально необходимый код. Проверки запускаются только через Docker согласно правилам проекта.
