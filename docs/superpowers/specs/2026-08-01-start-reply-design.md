# Приветствие по команде `/start`

## Цель

Заменить текущее общее приветствие Telegram-бота на согласованный текст, который сразу показывает основные возможности ассистента центра «Мороз и Солнце».

## Поведение

По команде `/start` бот отправляет одно статическое сообщение без вызова LLM. Сообщение состоит из трёх смысловых блоков, разделённых одной пустой строкой:

1. приветствие и представление;
2. список возможностей;
3. приглашение написать вопрос.

Точный текст:

```text
Здравствуйте! Я онлайн-ассистент центра «Мороз и Солнце» ❄️☀️

Помогу вам:
• узнать об услугах, ценах и программах
• подобрать подходящую процедуру
• записаться на удобное время
• перенести или отменить запись
• узнать о сертификатах и подготовке к визиту

Напишите, что вас интересует — я подскажу, с чего начать.
```

## Границы изменения

- Меняется только `START_REPLY` в корневом `.env`.
- Системный промпт, температура, лимиты ответа и остальные сообщения не меняются.
- Обработчики `/start`, consent-flow и доставка сообщений не меняются.
- Для применения к уже запущенному локальному контейнеру требуется его пересоздание, потому что Compose передаёт `START_REPLY` как переменную окружения при создании контейнера.

## Проверка

- Docker Compose успешно рендерит конфигурацию.
- В отрендеренном окружении `bot` находится точный согласованный текст с двумя двойными переводами строки.
- Одноразовый Docker-контейнер видит то же значение `START_REPLY`.
