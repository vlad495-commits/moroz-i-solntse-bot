## Границы

Это локальная автоматизированная проверка. Реальные Telegram, YCLIENTS и платные LLM не вызываются; staging и main не изменены. Качество живых ответов и выпуск на сервер этим отчётом не подтверждаются. Ответы Светы по программам всё ещё ожидаются.

## Что изменено

- Консультация использует ручной system.md и основной answer gateway; API каталога, автоматическая подстановка его фактов и детерминированные консультационные ответы удалены.
- Поминутная проверка ограничена явным форматом трёх услуг. Decimal проверяет каждое вхождение суммы, не разрешает её глобально. Тариф — только из файла промпта, не из истории.
- При ошибке answer gateway сохраняются trusted ответ записи и его клавиатура; повтор сообщения не повторяет dispatch.
- По решению владельца удалены редактор, save/rollback HTTP API, private CRUD, Redis reload/ack и задача listener в worker. Сам промпт и история БД сохранены.
- Технические CatalogService/CatalogVariant, list_services, YCLIENTS reader, hourly sync и TTL 24 часа сохранены. BookingService/coordinator, Router schema и миграции этим пакетом не менялись.
- Флаг консультационного grounding удалён из runtime, Compose, шаблона окружения и production validation. Управление включением Telegram-записи остаётся отдельным.
