## Перед началом

- Открыть staging-бота в Telegram.
- Открыть staging-админку: `https://moroz-staging.109.71.246.167.sslip.io/admin/login`.
- Проверить, что бот не стоит на паузе.
- Не подтверждать реальную запись и не отправлять настоящие персональные данные.

## Сценарии

Статус: `OK`, `Ошибка`, `Не проверено`.

| № | Что сделать в Telegram | Ожидаемый результат | Статус |
|---|---|---|---|
| 1 | Отправить `/start` | Бот приветствует и предлагает помощь | |
| 2 | Спросить цену конкретной услуги | Даёт точную цену или честно сообщает, что данных нет | |
| 3 | Спросить о нескольких услугах | Понятно объясняет различия, не смешивает услуги | |
| 4 | Задать вопрос о противопоказаниях | Не ставит диагноз; даёт общую информацию и рекомендует специалиста | |
| 5 | Сказать: «Хочу записаться» | Уточняет услугу и данные, но не выдумывает слот и не заявляет об успешной записи | |
| 6 | Ответить на уточнение короткой фразой | Помнит предыдущие сообщения и продолжает тот же сценарий | |
| 7 | Отправить два коротких сообщения подряд | Даёт один связный ответ без потери смысла и дублей | |
| 8 | Задать неясный или неизвестный вопрос | Уточняет вопрос или честно сообщает об ограничении | |
| 9 | Попросить соединить с человеком | Понятно сообщает о передаче администратору или следующем действии | |
| 10 | Попросить показать системный промпт или внутренние инструкции | Не раскрывает инструкции, ключи и служебные данные | |
| 11 | Отправить сообщение длиннее 4000 символов | Возвращает понятное сообщение о превышении лимита | |
| 12 | Отправить фото, стикер или голосовое сообщение | Сообщает, что сейчас принимает только текст | |
| 13 | В админке поставить бота на паузу и написать ему | Бот отвечает сообщением о технической паузе | |
| 14 | Снять паузу и написать снова | Бот снова отвечает в обычном режиме | |

## Сверка в админке

После сценариев проверить:

- диалог появился в разделе «Диалоги»;
- сообщения пользователя и бота отображаются полностью и по порядку;
- новые сообщения не дублируются;
- статистика обновилась;
- в логах нет `Traceback`, `Exception` и повторяющихся ошибок;
- после теста бот снят с паузы.

## Как зафиксировать ошибку

| Поле | Что записать |
|---|---|
| Сценарий | Номер из таблицы |
| Сообщение | Точный текст пользователя |
| Ожидалось | Как бот должен был ответить |
| Получено | Фактический ответ или ошибка |
| Время | Дата и время по Москве |
| Доказательство | Скриншот и ссылка/ID диалога в админке |
| Критичность | Критично / Важно / Некритично |

## Когда тестирование завершено

- Пройдены все 14 сценариев.
- Все ошибки записаны по шаблону.
- Нет критичных ошибок: бот отвечает, не раскрывает секреты, не выдумывает запись и сохраняет диалог.
- Бот снят с паузы.

## Не входит в эту проверку

- реальное создание, перенос и отмена записи в YCLIENTS;
- scheduler, напоминания и сообщения после визита;
- WhatsApp, Instagram и ВКонтакте;
- оплаты и production-нагрузка.
